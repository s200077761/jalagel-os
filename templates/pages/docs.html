Getting Started

Introduction

JALAGEL OS Pro is a commercial-grade, web-based operating system built with Python Flask. It provides a complete desktop environment with 50+ applications, enterprise SSL certificate management, and multi-tier licensing — all accessible from any modern web browser.

Key Features

  • 50+ Professional Apps — From productivity tools to developer utilities
  • Desktop Environment — Draggable windows, taskbar, start menu, and virtual desktops
  • SSL Certificate Store — 8 certificate types with full lifecycle management
  • Multi-tier Licensing — Free, Pro, and Enterprise plans
  • Dark Theme UI — Beautiful glassmorphism design with gradient accents
  • Cloud Sync — Your data follows you across devices

Quick Start Guide

Get up and running with JALAGEL OS Pro in under 5 minutes:

Self-Hosted Installation

To install JALAGEL OS Pro on your own server:

Terminal 
# Clone the repository
$ git clone https://github.com/jalagel-os/jalagel-os-pro.git
$ cd jalagel-os-pro

# Create virtual environment
$ python -m venv venv
$ source venv/bin/activate  # Linux/Mac
$ venv\Scripts\activate     # Windows

# Install dependencies
$ pip install -r requirements.txt

# Initialize database
$ flask seed

# Run the application
$ flask run --host=0.0.0.0 --port=5000

Certificate Management

Overview

JALAGEL OS Pro includes a comprehensive SSL certificate management system. You can purchase, generate, renew, and revoke certificates directly from the OS interface.

Certificates are essential for securing your custom domains, signing code, and establishing trust with your users.

Certificate Management Guide

Purchasing a Certificate

  1. Navigate to Certificates from the navigation bar or open the Certificate Manager app
  2. Browse the available certificate types
  3. Click Purchase on your chosen certificate
  4. Enter your domain name and complete the checkout
  5. The certificate will appear in "My Certificates" with status Pending

Generating/Activating

  1. Go to My Certificates
  2. Find your pending certificate and click Generate
  3. The system will create your certificate and private key
  4. Status changes to Active — your certificate is ready to use

Renewing

  1. Certificates expire after the purchased period (typically 1 year)
  2. Before expiry, you'll receive renewal notifications
  3. Click Renew in My Certificates to extend for another year

Revoking

  1. If a certificate is compromised, click Revoke immediately
  2. Revoked certificates cannot be renewed — you must purchase a new one
  3. The revocation is published to certificate transparency logs

Downloading

Active certificates can be downloaded in PEM format for use with web servers:

Certificate Files 
# Download these files from My Certificates:
certificate.pem   # Your SSL certificate
private_key.pem   # Private key (keep secure!)
chain.pem         # Certificate chain

# For Nginx:
ssl_certificate     /path/to/certificate.pem;
ssl_certificate_key /path/to/private_key.pem;
ssl_trusted_certificate /path/to/chain.pem;

API Reference

Authentication

All API endpoints require authentication. Use session-based auth (cookies) or API key authentication.

For API key auth, include your key in the header:

Headers 
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

Endpoints

Apps

GET /api/apps

List all available applications

POST /api/apps/launch

Launch an app (tracks usage). Body: {"app_id": 1}

Files

GET /api/files?parent_id={id}

List files and folders

POST /api/files

Create file or folder. Body: {"name": "...", "type": "file|folder"}

PUT /api/files/{id}

Update file. Body: {"name": "...", "content": "..."}

DELETE /api/files/{id}

Move file to trash

Notes

GET /api/notes

List all notes

POST /api/notes

Create note. Body: {"title": "...", "content": "...", "color": "#7C3AED"}

PUT /api/notes/{id}

Update note

DELETE /api/notes/{id}

Delete note

Todos

GET /api/todos

List all todos

POST /api/todos

Create todo. Body: {"text": "...", "priority": "medium"}

PUT /api/todos/{id}

Update todo

POST /api/todos/{id}/toggle

Toggle completion

DELETE /api/todos/{id}

Delete todo

Certificates

POST /api/certificates/purchase

Purchase certificate. Body: {"template_id": 1, "domain": "..."}

POST /api/certificates/generate

Generate SSL cert. Body: {"certificate_id": 1}

POST /api/certificates/renew

Renew certificate. Body: {"certificate_id": 1}

POST /api/certificates/revoke

Revoke certificate. Body: {"certificate_id": 1}

Admin

POST /api/admin/users/{id}/license

Update user license. Body: {"tier": "pro|enterprise", "expires": "2026-01-01"}

Admin Guide

Admin Dashboard

The admin dashboard provides an overview of your JALAGEL OS instance:

  • Total Users — Count of registered accounts
  • Active Users — Currently active accounts
  • Total Certificates — All issued certificates
  • Pending Certificates — Certificates awaiting generation
  • Premium Users — Pro and Enterprise subscribers
  • Storage Usage — Aggregated disk consumption

Access the dashboard at /admin (admin role required).

User Management

Admins can manage users from the Admin > Users page:

  • View Users — Browse all registered users with pagination (50 per page)
  • Edit User — Modify user details, roles, and license tiers
  • Deactivate — Disable user accounts without deleting data
  • Search — Find users by username, email, or license tier

License Management

Manage user licenses from the Admin > Licenses page:

  • View all Pro and Enterprise subscribers
  • See expiration dates and renewal status
  • Upgrade or downgrade user tiers
  • Extend license expiration dates

Frequently Asked Questions

General Questions

What is JALAGEL OS Pro?

A commercial-grade web-based operating system that runs entirely in your browser. It provides a full desktop environment with 50+ applications, SSL certificate management, and enterprise licensing.

Do I need to install anything?

No. JALAGEL OS Pro runs entirely in your web browser. For self-hosting, you can install it on your own server using the installation instructions above.

Is my data secure?

Yes. We use bcrypt password hashing, CSRF protection, session management, rate limiting, and input sanitization. All data is stored encrypted at rest.

Can I use it offline?

Currently, JALAGEL OS Pro requires an internet connection. Offline support is on our roadmap for a future release.

How do I report a bug?

Use the support chat in the OS, or email support@jalagel.com. Pro and Enterprise users get priority bug fixes.

Can I contribute?

We welcome contributions! Check our GitHub repository for contribution guidelines, coding standards, and open issues.

Troubleshooting

Desktop won't load

Clear your browser cache, ensure JavaScript is enabled, and try a hard refresh (Ctrl+F5). Check that you're using a supported browser version.

Apps are slow

Close unused app windows to free up memory. Check your internet connection speed. For best performance, use a modern browser on a device with 4GB+ RAM.

Can't upload files

Check your storage quota in Settings. Free users have 100MB, Pro has 5GB, and Enterprise has 50GB. Ensure your files don't exceed the individual file size limit (10MB).

Certificate generation failed

Ensure you've entered a valid domain name. Check that your license tier includes certificates. Contact support if the issue persists.
